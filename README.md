# AWS-SOA

Create or identify an S3 bucket and use the AWS CLI from your local machine to upload a file from the local system to the bucket. Verify that the file has been successfully uploaded.

#Description

In this practical, I created an Amazon S3 bucket using the AWS Management Console and used AWS CLI from my local Windows computer to upload a text file into the bucket. First, I configured the required IAM user and permissions so that my local system could securely connect with my AWS account. Then, I checked the AWS CLI installation and verified the connection. After that, I used the `aws s3 cp` command to upload my local file to the S3 bucket. Finally, I verified the uploaded file using both Command Prompt and the AWS Management Console to make sure the upload was successful. Through this practical, I got hands-on experience with AWS S3, IAM permissions, and using CLI commands for cloud storage.
